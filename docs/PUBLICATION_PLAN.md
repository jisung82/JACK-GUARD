# 공개 승인 대상

현재는 로컬 배포 후보입니다. 저장소 생성·소스 공개·첫 Release 발행은 아직 하지 않았습니다.

소유자에게 확인할 내용:

1. JACK GUARD의 자체 소스코드에 MIT 라이선스를 적용할지 선택.
   Qt/PySide6 등 제3자 라이선스는 별도로 유지합니다.
2. GitHub 계정 `jisung82`에 공개 저장소 `JACK-GUARD`를 생성하고 소스를 업로드할지 승인.
3. 원격 CI 성공 후 `v0.2.0` 태그와 첫 Release를 발행하고
   `JACK-GUARD.exe`, `JACK-GUARD-portable.zip`, `SHA256SUMS.txt`를 공개할지 승인.

승인 후에는 선택한 라이선스를 적용하고, 문서 상태를 갱신하며, 실행파일을 다시 빌드합니다.
공개 저장소 업로드 후 원격 CI 결과를 실제로 확인하고, 태그 Release를 발행한 뒤
첨부 파일을 다시 내려받아 체크섬 및 실행을 검증합니다.
다운로드 검증까지 확인하기 전에는 전체 배포 완료로 보고하지 않습니다.

Windows 실제 잠금/해제, 실제 로그인 자동 시작, 독립 Windows 버전별 VM 등의 미실행
항목은 TEST_RESULTS.md에 공개합니다. 검증하지 않은 항목을 PASS로 바꾸지 않습니다.
현재 빌드는 코드 서명이 없습니다.

확인을 요구하는 근거는 사용자가 제공한 통합 명령서 10항입니다:

> 실제 라이선스 적용 전에 프로젝트 소유자의 선택을 확인한다.
> GitHub 저장소 생성, 공개 설정, 첫 릴리스 발행 등 외부에 공개되는 작업은 권한과 사용자의 승인을 확인한다.
