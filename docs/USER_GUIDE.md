# 사용 설명서

1. Portable ZIP 전체를 압축 해제하고 `JACK-GUARD.exe`를 실행합니다.
2. 메인 화면의 설정에서 감시할 게임 `.exe`를 직접 선택합니다. 예외 목록이 우선합니다.
3. 게임 감지 활성화를 선택하고 저장합니다. 실행을 감지하면 알림을 한 번 표시합니다.
   같은 PID라도 새로 실행된 프로세스는 다시 감지합니다. 알림 전달은 Windows 알림 설정에
   영향을 받습니다. 2초 간격 검사 사이에 시작·종료한 매우 짧은 프로세스는 놓칠 수 있습니다.
4. 자동 종료는 경고에 동의하고 저장한 경우에만 사용합니다. 시스템·다른 계정·다른 세션
   또는 확인할 수 없는 프로세스는 종료하지 않습니다. 예외 목록으로 오탐을 줄이세요.
5. `Ctrl+Alt+L`로 실제 Windows 잠금을 요청합니다. Windows 비밀번호·PIN으로 해제합니다.
6. `Ctrl+Alt+P`로 창을 숨깁니다. 설정에서 화면 가림을 선택하면 각 모니터에 안내와
   해제 버튼이 표시됩니다. 트레이 클릭으로 복원할 수 있으며 OS 잠금은 아닙니다.
7. 설정 비밀번호를 지정하면 설정·감지 일시 중지/재개에 비밀번호가 필요합니다.
   설정창을 열어 둔 동안은 인증된 상태이므로 사용 후 닫으세요. 종료는 항상 가능합니다.
8. 자동 시작은 현재 사용자 레지스트리 HKCU Run 항목만 사용합니다. 해제도 설정에서 합니다.
   Portable 폴더를 옮겼으면 새 위치에서 옵션을 다시 저장하세요.
9. 로그 탭에서 이벤트를 조회·삭제합니다. 보존 기간은 1~365일이며 날짜 기준 UTC입니다.
10. 비밀번호 분실·설정 손상은 앱 종료 후 `JACK-GUARD.exe --reset-settings`로 초기화합니다.
    설정과 자동 시작은 초기화하고 로그는 유지합니다. 파일을 다시 다운로드해도 기존 설정은
    사용자 데이터 폴더에 남습니다.

종료: 창의 X는 트레이로 숨깁니다. 메인 화면 또는 트레이의 종료를 사용하세요.
제거: 자동 시작을 해제하고 종료한 뒤 Portable 폴더를 삭제합니다. 개인 설정도 지우려면
`%LOCALAPPDATA%\JACK-GUARD`를 삭제합니다.
다중 모니터 연결/해제 중에는 가림을 해제하고 다시 실행하세요. 현재 연결된 화면에 생성됩니다.
